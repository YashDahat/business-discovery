npm_packages note — Radix/shadcn decision tree (affects which packages you list):
1. Radix UI primitive for interactive/accessible components that have one (Select,
   Dialog, AlertDialog, Checkbox, Label, RadioGroup, Switch, Tabs, Accordion, Popover,
   DropdownMenu, Tooltip, Toast) → add @radix-ui/react-<name> to npm_packages per one used.
2. shadcn components (Button, Card, Input, Textarea, Table, Badge, Form, Separator,
   Skeleton, Progress) come from @/components/ui/* — no npm package entry, and NEVER
   plan src/components/ui/ files (the worker runs `shadcn add` automatically).
3. Everything else is plain HTML + Tailwind. For className merging use clsx.
